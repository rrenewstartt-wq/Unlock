# /review [ep]

인자가 없으면 가장 최근에 수정한 `episodes/*`.

## 1. 기술 검사
```bash
cd episodes/<ep> && python3 data/build_script.py && python3 build.py && npx hyperframes check --json
```
오류 0. 경고는 하나씩 읽는다(첫 프레임에 숨김이 안 먹는 `tl.set` 은 CSS `opacity: 0` 으로, 읽기 시간 부족은 노출 연장).

## 2. 사실
`data/facts.md` 와 `data/script.txt` 를 한 줄씩 대조한다. 근거 없는 자막, ⚠️ 인데 단정한 자막,
화면에만 있는 사실(이름표·카드 글귀)도 확인한다. 원문에 없는 세부("연필로 썼다", "불붙은 담배")는 지운다.

## 3. 화면
장면마다 자막 시각 근처 2~3장씩 스냅샷을 찍어 본다(`npx hyperframes snapshot --at ...`, 연락처 시트 Read).
`docs/visual-style.md` 도식 원칙 7개로 판정한다:
- 의미 없는 노드·선, 이름표 없는 요소, 한 번에 다 뜨는 도식
- 주인공 요소 40% 미만, 32px 미만 글자, 줄바꿈 깨짐
- 글자 뒤로 지나가는 선, 빈 화면(장면 시작·전환 순간 포함)
- `재현`/`도식` 표기 누락, 장면당 앰버 초점 2개 이상
- 3D: 카메라가 벽에 막힘, 형체가 읽히지 않음(피라미드처럼 보이는 계단 등), 너무 어둡거나 밝은 하늘 위 흰 글자

## 4. 고치고 다시
고친 장면만 다시 스냅샷. 같은 장면을 3번 고쳐도 안 되면 멈추고 남은 문제를 보고한다.
기준을 낮춰서 통과시키지 않는다.
