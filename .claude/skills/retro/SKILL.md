# /retro [ep | 하네스]

목적: 같은 문제가 두 번 생기지 않게 한다. 사람 탓도, 모델 탓도 아니라 **하네스(규칙·도구·팀·관문)를 고친다.**

## 1. 사실 모으기 (추측 금지)
- `git log --since=<지난 회고>` 와 `STATUS.md` 의 날짜별 항목, `docs/retros/` 의 지난 회고(고칠 것이 실제로 고쳐졌나).
- 숫자: `python3 scripts/parity_check.py episodes/<ep>`(통과·실패·예외), visual-critic·fact-checker·parity-judge 의 마지막 보고,
  업로드했다면 `data/performance/<ep>.md`(`performance-analyst`).
- 막힌 것: 사람 결정 대기, 접근이 막힌 사이트(우회하지 않은 것), 도구 버그.

## 2. 정리 (팀별, `docs/teams.md` 의 7팀)
| 팀 | 잘 된 것 | 문제 | 원인(규칙·도구·팀·관문 중 무엇) | 고칠 것 | 담당 | 기한 |
문제마다 "다시 생기지 않게 무엇을 바꾸나"를 하나씩: 기준 문서, 스크립트, 에이전트 지침, 관문. "더 조심한다"는 고칠 것이 아니다.

## 3. 레퍼런스 동급까지 남은 차이
영역(대본·화면·소리·사실·썸네일·메타)마다: 지금 상태 → 동급 조건 → 막는 것(사람 결정이면 그렇다고).

## 4. 남기기
`docs/retros/YYYY-MM-DD-<ep 또는 harness>.md` 로 저장하고, 고칠 것 중 **사람 승인이 필요 없는 것은 바로 고친다**(커밋 메시지에 회고 파일 이름).
기준 자체를 바꾸는 것(길이, 공식, 관문 숫자)은 사람에게 보여 주고 승인받은 뒤 반영한다. `STATUS.md` 의 "바로 다음 할 일"을 갱신한다.
