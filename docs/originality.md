# 벤치마킹과 복제의 경계

이 하네스의 이름은 벤치마크 채널(@unlock_kr)을 가리키지만, **채널을 복제하지 않는다.**
채널 전체를 똑같이 만들면 저작권 침해·사칭 신고 대상이 되고, 유튜브 파트너 프로그램의
"재사용·진정성 없는 콘텐츠" 기준에 걸려 수익 창출이 막힌다.

| 가져온다 (형식) | 가져오지 않는다 (표현) |
|---|---|
| 제목 공식("N년 만에 ~") | 그 채널의 제목 문장 그대로 |
| 대본 7단계 구조, 말투(~습니다/~죠) | 대본 문장, 자막 텍스트 |
| 3D 재연 + 인포그래픽 + 하단 자막이라는 화면 문법 | 그 채널의 3D 장면·그래픽·화면 캡처 |
| 썸네일 원리(단색 + 상징물 + 그레인) | 썸네일 이미지, 빨간 단색 톤 |
| 해외 실화 미제사건이라는 장르 | 같은 사건을 그 채널 대본을 보고 다시 쓰기 |
| | 채널명·로고·연락처·말버릇 |

- 같은 사건을 다루는 것은 괜찮다(사실은 저작권 대상이 아님). 단, 그 채널이 아니라 1차 자료(판결문, 당시 보도, 공식 발표)를 보고 새로 쓴다.
- 벤치마크 원본 자료(`data/benchmark/*/raw/`)는 분석용으로만 보고 커밋·재사용하지 않는다.
- 사실 확인은 `episodes/<ep>/data/facts.md` 에 자막별로 남기고, ⚠️ 항목은 업로드 전에 1차 자료로 확인한다.
