# 벤치마킹 범위

**2026-11-25 사용자 지시:** 대본·썸네일·그래픽의 **스타일·공식·포맷은 레퍼런스(@unlock_kr)와 똑같이** 맞춘다.
새로 만드는 것은 문장과 그림 파일 자체뿐이다 — 글자 그대로 옮긴 문장, 그 채널의 이미지·영상 파일, 채널명은
저작권 침해·사칭 신고 대상이고, 유튜브 "재사용 콘텐츠" 기준에 걸려 수익 창출이 막힌다.

| 똑같이 맞춘다 (스타일·공식·포맷) | 그대로 쓰지 않는다 |
|---|---|
| 제목 공식("N년 만에 ~"), 제목 길이·리듬 | 그 채널의 제목 문장 글자 그대로 |
| 대본 7단계 구조, 말투(~습니다/~죠), 문장 길이·전환 방식·질문 던지는 위치 | 대본·자막 문장 글자 그대로 |
| 3D 재연 + 인포그래픽 + 하단 자막 화면 문법, 도식 종류·배치·강조색(빨강 포함) | 그 채널의 3D 장면·그래픽 파일·화면 캡처 |
| 썸네일 원리·구도·색(빨간 단색 + 상징물 + 그레인) | 썸네일 이미지 파일, 그 한 장을 베낀 것(`bench_hash` 6 미만) |
| 해외 실화 미제사건 장르 | 채널명·로고·연락처 |

- 같은 사건을 다루는 것은 괜찮다(사실은 저작권 대상이 아님). 사실은 1차 자료(판결문, 당시 보도, 공식 발표)로 확인한다.
- 벤치마크 원본 자료(`data/benchmark/*/raw/`)는 분석용으로만 보고 커밋하지 않는다.
- 사실 확인은 `episodes/<ep>/data/facts.md` 에 자막별로 남기고, ⚠️ 항목은 업로드 전에 1차 자료로 확인한다.
