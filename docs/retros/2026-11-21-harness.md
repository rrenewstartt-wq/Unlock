범위: 저장소 이전(2026-11-20) 이후 커밋 15개. 레퍼런스(@unlock_kr) 동급을 목표로 팀·기준·엔진을 바꾼 이틀.

## 3. 레퍼런스 동급까지 남은 차이
| 영역 | 지금 | 동급 조건 | 막는 것 |
|---|---|---|---|
| 대본 | 3분 시험편. 형식 항목(날짜 도입·떡밥·되감기·질문·어미)은 통과 | 16~20분, 단서 8~12개, 소품 회수 | **2편 실제 제작**(사건 선택 = 사람) |
| 화면 | 3D 75% 가 사실적 인물·실사 세트, 실제 사진 후킹 + 3초 컷, 도식 원칙 | 3D 100% film 키트, 핵심 장면 5개 이상·사진 60%, 2~3분마다 기록 컷, 영화식 조명 | 2편 제작 / **같은 형식에서 잘 되는 채널은 화면이 사진처럼 보인다**(사진 같은 생성 이미지를 쓸지 = 사람, 유료) |
| 소리 | 효과음만 | 본인 내레이션 + 음악 베드 + -16~-14 LUFS | **사람:** 녹음, 음악 출처 |
| 사실 | ep01 ⚠️ 2개 | ⚠️ 0, fact-checker 통과 | 1차 자료 확인(도구로 가능) |
| 썸네일 | 통과안 3개 | 통과안 2~3개 + 선택 | 사람 선택 |
| 메타 | upload.json 없음 | 제목 공식 + 한·일 태그 8개 이상 | 제작 단계에서 씀 |

**정직한 결론:** 하네스는 이제 레퍼런스 동급이 아니면 "완성"이라고 말하지 못하게 막는다(`parity_check --strict` + `parity-judge`). 하지만 하네스만으로 동급이 **나오지는 않는다.** 세 가지가 더 필요하다:
① 2편을 실제로 끝까지 돌려 17명의 미검증 팀원을 검증하는 것,
② 사람만 줄 수 있는 내레이션 녹음과 음악,
③ 화면을 사진처럼 만들지에 대한 결정.
셋 중 하나라도 빠지면 판정은 "미달"로 남고, 그렇게 보고한다.
