# 레퍼런스 동급 기준 (quality bar)

목표: **@unlock_kr 롱폼과 나란히 놓았을 때 빠지지 않는 한 편.** "비슷해 보인다"가 아니라 아래 숫자로 판정한다.
자동 측정: `python3 scripts/parity_check.py episodes/<ep>` (렌더가 있으면 화면 변화율·컷 길이·음량까지).
넘기기 전 관문: `--strict` 가 통과하고, `visual-critic` 의 P0 가 0개이고, `parity-judge` 가 "동급"이라고 판정할 것.

근거: 레퍼런스 4편(`data/benchmark/unlock_kr/summary.json`, `docs/benchmark-report.md`). 최고 조회수 편은 10분 56초, 나머지는 16~19분.

## 1. 대본 — 담당 `script-writer`, 검수 `script-critic`
| 항목 | 기준 | 측정 |
|---|---|---|
| 길이 | 12~20분, **기본 16~20분**(경쟁 채널 17곳: 16~30분 단일 사건 영상이 8~12분보다 배수 1.13 대 0.83, `docs/competitor-report.md`) | 자동 |
| 분량 | 6,000~8,000자, 분당 380~420자(내레이션 기준) | 자동 |
| 도입 | 첫 자막이 연·월·일·시각 + 감각 디테일 하나 | 자동 + 눈 |
| 떡밥 | 60초 안에 "무려 N년" 같은 걸린 시간·규모 | 자동 |
| 되감기 | "~전으로 되돌려 보겠습니다"로 시간순 시작 | 자동 |
| 질문 | 편당 5~9개, 첫 질문은 8~20% 지점, 그 뒤 단서 묶음마다 | 자동 |
| 어미 | ~습니다와 ~죠를 섞는다(~죠 30~60%), 같은 어미 3번 연속 금지 | 자동 |
| 단서 | 수사 단계에 단서 6~10개, 단서 하나 = 장면 하나 | 눈 |
| 마무리 | 아직 모르는 것을 정직하게 + **도입의 물건을 다시 꺼낸다** | 자동(겹치는 말) + 눈 |
| 자막 | 한 줄 22자 안팎, 최대 28자, 한 줄에 사실 하나 | 자동 |
| 사실 | 모든 자막이 `facts.md` 근거, 업로드 전 ⚠️ 0개 | 자동 + `source-verifier` |

## 2. 화면 — 연출 `storyboard-director`, 검수 `visual-critic`
| 항목 | 기준 | 측정 |
|---|---|---|
| 컷 | 중앙값 3~8초, 한 화면 최대 12초. 10초 간격 프레임의 74~92%가 이전과 다른 화면(레퍼런스 실측) | 자동(렌더) |
| 배분 | 3D 재연 35~65% / 2D 도식 25~45% / 실제 자료 3장면 이상 | 자동 |
| 3D 인물 | **옷·머리·손이 있는 사실적 인물**(film 키트, `docs/visual-style.md` "3D 재연"). 기본 도형 마네킹(`world.js makeFigure`) 금지 | 자동 |
| 3D 세트 | 실사 질감(Poly Haven PBR)·실제 하늘(HDRI)·실사 소품 모델. 단색 상자·평면만으로 된 세트 금지 | 자동(키트 사용) + 눈 |
| 조명 | 영화식: 키 하나 + 림/배경 분리 + 앰버 초점 하나. 평평한 회색 화면 금지 | 눈 |
| 인물 근접 | 사실적 인물이라도 **가슴 위 클로즈업 금지**(저해상도 얼굴·목 이음새가 드러남). 소품의 디테일은 소품만 따로 찍는 인서트 컷으로 | 눈 |
| 도식 | `docs/visual-style.md` 도식 원칙 7개. 타임라인·관계도·부검 카드·숫자 카운터·지도·CCTV/휴대폰 UI 중 사건에 맞는 것 | 눈 |
| 실제 자료 | 저작권 만료·공공 기록 사진, 지도, 신문 지면을 `assets/archive/` 에 두고 `assets/archive/SOURCES.md` 에 출처·라이선스. 피해자·유족 사진, 잔혹한 사진 금지 | 자동 + `archive-researcher` |
| 표기 | 3D 는 `재현`, 개념도는 `도식` | 자동 |

## 3. 소리 — 담당 `sound-designer`
| 항목 | 기준 | 측정 |
|---|---|---|
| 내레이션 | 본인 목소리 복제(`docs/voice.md`). 없으면 "동급" 판정 불가 | 자동 |
| 음악 | 장면 분위기별 베드 2~4곡, 라이선스 `assets/music/LICENSE.md`. 출처는 사용자 소유 곡 또는 사용 허가가 명확한 곡 | 자동 |
| 효과음 | 화면에 원인이 있는 것만, 같은 소리는 2~3개 테이크를 번갈아 | 자동 + 눈 |
| 음량 | 통합 -16~-14 LUFS, 실제 피크 -1 dB 이하, 내레이션 위 음악 약 -20 dB | 자동(렌더). **측정만 했으면 "들어 보지 않았다"고 보고** |

## 4. 썸네일·메타 — 썸네일 팀(`/thumbnail`)
| 항목 | 기준 |
|---|---|
| 썸네일 | `docs/thumbnail-benchmark.md` 규칙 + 문구 검수 통과안 2~3개 |
| 제목 | `docs/script-formula.md` 제목 공식 중 하나(N년 만에 > 최상급, 물음 제목은 피함), 썸네일 문구와 겹치지 않게 |
| upload.json | `{"title", "description", "tags"}` — 레퍼런스처럼 한국어 + 일본어 태그(未解決事件, 衝撃の実話 등) 8개 이상 |

## 5. 판정
- `parity-judge` 가 위 표 + `visual-critic` 보고 + 레퍼런스 설명을 놓고 영역마다 **동급 / 근접 / 미달** 을 매긴다.
- 하나라도 미달이면 "완성"이라고 보고하지 않는다. 미달 항목, 담당자, 고칠 방법을 표로 낸다.
- 사람이 정할 것(목소리 녹음, 음악 출처, 유료 생성 이미지)은 판정과 별도로 "사람 결정 대기"로 적는다.
