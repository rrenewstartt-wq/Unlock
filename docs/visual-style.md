# 화면 스타일과 도식 원칙

## 룩
- 바탕 #1E2125(차가운 콘크리트 회색) + 그레인 7%, 비네트. 잉크 #E9E5DD.
- **강조색은 나트륨 가로등 앰버 #F0A23B 하나**, 장면당 초점 한 곳(가로등, 핵심 증거, 핵심 숫자, 못 찾은 것).
  벤치마크의 빨간 단색은 쓰지 않는다.
- 글꼴: 제목·핵심 단어 Black Han Sans, 본문·자막 Gothic A1 Medium(둘 다 OFL, `assets/fonts`).
- 자막: 40px, 아래에서 74px, **박스 없이** 그림자(0 0 3px + 0 2px 10px 검정)로 읽히게. 화면을 덜 가린다(벤치마크와 같은 방식).

## 3D 재연 (Three.js, `assets/lib/world.js`)
- `makeFigure(mat, {top, bottom, shoe})`: 얼굴 없는 관절 마네킹. 옷 재질을 주면 소품(담배 등)이 대비로 읽힌다.
- `poseStanding`, `poseLying`, `cameraAt(keys, t)`: 카메라 키에 `cut: true` 를 주면 그 시각에 **하드 컷**.
- **컷 속도:** 3D 장면은 `scenes_kit.cam_shots([(t, pos, look, fov), ...], dur)` 로 자막마다 한 컷(3~5초), 컷마다 느린 푸시인.
  한 장면을 카메라 이동 한 번으로 15초 넘게 끌지 않는다(벤치마크 컷 간격 약 4~8초).
- 세트는 사건마다 새로 만든다(ep01: `beach.js` 해변 3모드, `station.js` 보관소). 모든 프레임은 시간 t 의 순수 함수.
- 3D 장면에는 항상 `재현` 표기. 사실과 다른 디테일 금지(ep01: 발견 당시 담배는 타고 있지 않았으므로 불씨 없음).

## 도식 원칙 (모든 에피소드)
1. **도식은 설명한다.** 의미 없는 노드·선 금지. 모든 요소에 이름표, 자막이 그것을 말하는 순간 하나씩 등장.
2. **크기:** 주인공 요소가 화면의 40% 이상. 읽는 글자 32px 이상(이름표 34~48px, 핵심 단어 46px+).
3. **겹침 금지:** 글자 뒤로 선·노드가 지나가지 않는다. 다음 정보가 오면 이전 도식은 빠지거나 0.25 이하로 물러난다.
4. **하나의 시각 언어:** 바탕 = 거의 검은 보드(`scenes_kit.BOARD`) / 사람 = 외곽선 사람 카드(`person_card`) / 서류 = 종이색 #D9D5CC 카드 + 진한 글자 /
   이름표 = 어두운 바탕 + 왼쪽 8px 띠 / 선 4px 둥근 끝 / 노드 = 속 빈 원 / 모르는 사람 = 점선 카드 + "?".
5. **정직한 표기:** 그린 것은 `재현`, 개념도는 `도식 · 실제 ○○ 아님`. 원문에 없는 세부를 그림으로 덧붙이지 않는다.
6. **패턴:**
   - 숫자 → 축 위에서 채워지고 숫자가 착지(타임라인 → 73년)
   - 풀린 것 / 안 풀린 것 → 장부 2행(앰버는 안 풀린 쪽)
   - 연결 → 출발점(전화번호)에서 실제로 선이 나가 카드에 닿는다
   - 방법 설명 → 한 줄 흐름(입력 → 데이터베이스 → 공통 조상 → 빈칸 → 이름 카드)
   - 일치 → 두 견본을 나란히 + `=` + 한 줄 결론
7. **금지:** 어두운 허공에 작은 요소 띄우기, 글로우·파티클, 카드 3개 나열, 모든 요소가 페이드+위로 슬라이드, 코너 장식, 실제 인물 얼굴.

## 썸네일
- **자세한 기준은 `docs/thumbnail-benchmark.md`(장르 히트작 분석, 우선) → `docs/thumbnail-formula.md`(썸네일 팀, `/thumbnail`).** 아래는 옛 요약이며 두 줄 큰 글자·기록 사진 사용으로 개정됐다.
- 원리는 벤치마크와 같다: **단색 + 그레인 + 상징물 하나**. 색은 앰버 듀오톤.
- **상징물 하나를 화면 가득** 클로즈업한다(ep01: 돌돌 말린 'Tamám Shud' 종이). 넓은 장면은 휴대폰 크기에서 읽히지 않는다.
  어두운 바탕 + 밝은 물체로 대비를 만든다(듀오톤은 밝기만 남긴다).
- 컨셉마다 `thumbnail/cN.html`(thumbkit 3D 정지 장면) → `bash scripts/thumbnail.sh episodes/<ep>` 로 촬영·보정·검수.
- 글자 없는 판과 짧은 글자 판(숫자 + 4~6자) 두 가지를 만든다.
