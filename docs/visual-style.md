# 화면 스타일과 도식 원칙

> **2026-11-25: 화면의 목표는 `docs/reference-look.md`(레퍼런스 룩 숫자·문법)다.** 이 문서와 어긋나면 reference-look 이 먼저다. 아래 앰버·검은 보드 규칙은 진행 중인 ep02 의 룩이고, 새 편은 reference-look 을 따른다(강조색은 사람 결정 대기).

## 룩
- 바탕 #1E2125(차가운 콘크리트 회색) + 그레인 7%, 비네트. 잉크 #E9E5DD.
- **강조색은 나트륨 가로등 앰버 #F0A23B 하나**, 장면당 초점 한 곳(가로등, 핵심 증거, 핵심 숫자, 못 찾은 것).
  레퍼런스처럼 빨강을 써도 된다(2026-11-25 사용자 지시) — 바꿀지는 에피소드 SPEC 에서 정한다.
- 글꼴: 제목·핵심 단어 Black Han Sans, 본문·자막 Gothic A1 Medium(둘 다 OFL, `assets/fonts`).
- 자막: 40px, 아래에서 74px, **박스 없이** 그림자(0 0 3px + 0 2px 10px 검정)로 읽히게. 화면을 덜 가린다(벤치마크와 같은 방식).

## 실제 사진 (핵심 장면은 사진이 먼저)
- 핵심 장면(발견, 결정적 증거, 인물, 장소, 반전, 엔딩 — `docs/quality-bar.md`)은 **실제 기록 사진을 먼저** 쓴다. 3D·도식은 사진을 쓸 수 없을 때만.
- **한 컷 약 3초.** 처음 후킹 1~3장 + 중간 하이라이트마다 3초 컷(`scenes_kit.archive_insert(sid, at, src, size, focus=...)` 를 3D·도식 장면 안에 끼움).
- `scenes_kit.archive_scene(sid, dur, q, shots)`: 사진마다 한 컷, `기록` 표기(앰버 테두리), 출처 한 줄, 흑백·바랜 톤·그레인
  (HyperFrames `data-color-grading` `mono-fade` — 모든 기록 사진에 같은 룩, CSS 필터로 흉내 내지 않는다).
- 작은 옛 사진은 보드 위 인화 사진(흰 테두리, ±1.2° 기울기, 그림자), 큰 사진(긴 변 1600px 이상)만 `mode: "cover"`.
- 강조는 앰버 동그라미 하나(`focus`), 자막이 그 부분을 말하는 순간에 그려진다. 화살표·빨간 동그라미 여러 개는 쓰지 않는다.
- 출처·라이선스는 `assets/archive/SOURCES.md` 에 먼저 적고, 화면의 출처 문구는 그 대장의 "표기 문구"를 그대로 쓴다.
- 금지: 시신·피·부상 사진, 피해자·유족의 사적 사진, 미성년자 얼굴, 확정 판결 없는 관련자 얼굴, 언론사·방송 화면.

## 3D 재연 (film 키트: `thumbkit/film.js` → `python3 scripts/kit3d.py episodes/<ep>`)
- **레퍼런스 급의 기본값:** 옷·머리·손이 있는 사실적 얼굴 없는 인물(Quaternius CC0, `f.figure("film" | "filmWoman" | "onlooker")`),
  Poly Haven CC0 실사 질감(`f.material`, `f.surface`)·실제 하늘(HDRI)·실사 소품 모델(`f.model`). 자산은 `episodes/<ep>/kit3d.json` 에 적는다.
- 세트 파일은 `film(stage, key, opts, async (f) => {...; return (t) => {...}})` 한 함수(참고: ep01 `assets/lib/beach.js`).
  무거운 준비는 `window.__hf.buildReady` 약속으로 끝내고 render(t)는 t 의 순수 함수.
- 공유 질감은 반복 설정도 공유한다: 한 재질을 여러 곳에 다른 반복으로 쓰면 `f.tiled(mat, rx, ry)`.
- **인물 가슴 위 클로즈업 금지**(저해상도 얼굴·목 이음새가 드러난다). 담배·쪽지 같은 작은 소품은 소품만 찍는 인서트 컷으로.
- 조명: 키 하나 + 림 또는 배경 분리 + 앰버 초점 하나. 평평한 회색은 실패.
- `world.js` 의 기본 도형 마네킹(`makeFigure`)은 옛 방식이다. 새 장면에는 쓰지 않는다(ep01 보관소 장면이 아직 이 방식).
- `cameraAt(keys, t)`: 카메라 키에 `cut: true` 를 주면 그 시각에 **하드 컷**.
- **컷 속도:** 3D 장면은 `scenes_kit.cam_shots([(t, pos, look, fov), ...], dur)` 로 자막마다 한 컷(3~5초), 컷마다 느린 푸시인.
  한 장면을 카메라 이동 한 번으로 15초 넘게 끌지 않는다(벤치마크 컷 간격 약 4~8초).
- 세트는 사건마다 새로 만든다(ep01: `beach.js` 해변 3모드, `station.js` 보관소). 모든 프레임은 시간 t 의 순수 함수.
- 3D 장면에는 항상 `재현` 표기. 사실과 다른 디테일 금지(ep01: 발견 당시 담배는 타고 있지 않았으므로 불씨 없음).

## 도식 원칙 (모든 에피소드)
1. **도식은 설명한다.** 의미 없는 노드·선 금지. 모든 요소에 이름표, 자막이 그것을 말하는 순간 하나씩 등장.
2. **크기:** 주인공 요소가 화면의 40% 이상. 읽는 글자 32px 이상(이름표 34~48px, 핵심 단어 46px+).
3. **겹침 금지:** 글자 뒤로 선·노드가 지나가지 않는다. 다음 정보가 오면 이전 도식은 빠지거나 0.25 이하로 물러난다.
4. **하나의 시각 언어:** 바탕 = 거의 검은 보드(`scenes_kit.BOARD`) / 사람 = 외곽선 사람 카드(`person_card`) / 서류 = 종이색 #D9D5CC 카드 + 진한 글자 /
   이름표 = 어두운 바탕 + 왼쪽 8px 띠 / 선 4px 둥근 끝 / 노드 = 속 빈 원 / 모르는 사람 = 점선 카드 + "?".
5. **정직한 표기:** 그린 것은 `재현`, 개념도는 `도식 · 실제 ○○ 아님`. 원문에 없는 세부를 그림으로 덧붙이지 않는다.
6. **패턴:**
   - 숫자 → 축 위에서 채워지고 숫자가 착지(타임라인 → 73년)
   - 풀린 것 / 안 풀린 것 → 장부 2행(앰버는 안 풀린 쪽)
   - 연결 → 출발점(전화번호)에서 실제로 선이 나가 카드에 닿는다
   - 방법 설명 → 한 줄 흐름(입력 → 데이터베이스 → 공통 조상 → 빈칸 → 이름 카드)
   - 일치 → 두 견본을 나란히 + `=` + 한 줄 결론
7. **금지:** 어두운 허공에 작은 요소 띄우기, 글로우·파티클, 카드 3개 나열, 모든 요소가 페이드+위로 슬라이드, 코너 장식, 실제 인물 얼굴.

## 썸네일
- **자세한 기준은 `docs/thumbnail-benchmark.md`(장르 히트작 분석, 우선) → `docs/thumbnail-formula.md`(썸네일 팀, `/thumbnail`).** 아래는 옛 요약이며 두 줄 큰 글자·기록 사진 사용으로 개정됐다.
- 원리는 벤치마크와 같다: **단색 + 그레인 + 상징물 하나**. 색은 앰버 듀오톤.
- **상징물 하나를 화면 가득** 클로즈업한다(ep01: 돌돌 말린 'Tamám Shud' 종이). 넓은 장면은 휴대폰 크기에서 읽히지 않는다.
  어두운 바탕 + 밝은 물체로 대비를 만든다(듀오톤은 밝기만 남긴다).
- 컨셉마다 `thumbnail/cN.html`(thumbkit 3D 정지 장면) → `bash scripts/thumbnail.sh episodes/<ep>` 로 촬영·보정·검수.
- 글자 없는 판과 짧은 글자 판(숫자 + 4~6자) 두 가지를 만든다.
