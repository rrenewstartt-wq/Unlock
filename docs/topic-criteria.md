# 소재 기준 — 기획·소재 발굴 팀

## 이 채널에 맞는 사건
- **"N년 만에"가 성립한다:** 사건과 해결(신원 확인, 체포, 판결, 자백, 새 증거) 사이에 10년 이상. 그 숫자가 제목의 떡밥이 된다.
- **밝혀진 것이 공식적이다:** 판결, 수사기관 발표, 신원 확인 발표가 있다. 추측·음모론만으로 성립하는 사건은 제외.
- **장면으로 만들 수 있다:** 장소(해변, 역, 골목, 집)와 핵심 물건(증거물)이 있어 3D 재연과 도식으로 보여줄 수 있다.
- **1차 자료가 있다:** 판결문, 경찰·검찰 발표, 당시 보도, 공식 기록. 출처 2개 이상.

## 점수 (각 1~5, `config/topics.json` 가중치)
| 항목 | 5점 | 1점 |
|---|---|---|
| hook (×1.5) | "N년 만에" + 반전·뜻밖의 단서가 한 줄로 설명됨 | 떡밥이 약함 |
| resolution (×1.2) | 판결·공식 신원 확인으로 결말이 확정 | 결말 불명확·논쟁 중 |
| sources (×1.2) | 1차 자료 + 여러 언어 보도 | 2차 블로그뿐 |
| visual (×1.0) | 장소·물건·단서가 많아 장면 10개 이상 | 말로만 설명 |
| novelty (×1.0) | 한국 유튜브에서 거의 안 다룸 | 이미 여러 채널이 다룸 |
| audience (×1.0) | 한국 시청자에게 친숙한 지역·주제(일본·미국, DNA 수사, 공소시효) | 거리가 먼 소재 |
| risk (×−1.5) | 생존 관련자 지목·미성년자·진행 중 재판·잔혹 묘사 중심 | 위험 요소 거의 없음 |

## 무조건 제외 (`config/topics.json → hard_exclude`)
- 확정 판결 없이 생존한 특정인을 범인으로 지목해야 성립
- 미성년자 신원이 드러남 / 재판 진행 중 / 성범죄 묘사가 중심
- 우리나 벤치마크 채널이 이미 다룸(`data/topics/covered.json`, `scripts/topics.py check`)
- **국내 사건:** 사실을 적시해도 명예훼손이 될 수 있다. 확정 판결·공식 발표만, 판결 확정자·공인 외 실명 금지, 위험 +1.
