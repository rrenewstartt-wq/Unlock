# 레퍼런스 룩 — 화면을 레퍼런스와 같게 만드는 기준

출처: 사용자가 준 @unlock_kr 「14년만에 풀린 일본 장기 미제사건」(11:04) 휴대폰 화면 녹화 3개(2026-11-25, 약 25초).
프레임 19장은 `data/benchmark/unlock_kr/raw/screen-rec/`에 있고 커밋하지 않는다. 숫자는 `python3 scripts/look_check.py --ref`로 다시 잴 수 있다.
CLAUDE.md 규칙 1(2026-11-25)에 따라 **스타일·공식·포맷은 똑같이** 맞춘다. 그 영상의 장면을 똑같이 다시 짓지는 않는다. 사건이 다르니 집·인물·소품도 다르다.
화면 녹화라서 휴대폰 감마와 압축이 섞여 있다. 숫자는 ±10% 띠로 보고, 더 좋은 레퍼런스 프레임이 생기면 다시 잰다.

## 2. 문법(보고 적은 것) — 담당
1. **조명:** 낮은 해 하나 + **나뭇잎 그림자(고보)**. 벽·문·창·바닥에 큰 잎 그림자가 거의 모든 실외 컷에 깔린다. 밤·실내는 남색 어둠 + 창빛 하나. 가득 채운 환경광 없음. — `cinematographer`
2. **재질:** 건축 시각화 같은 **클레이 톤**. 벽·지붕·바닥·가구는 무광 회백색에 질감이 약하고, 장면마다 **주인공 소재 하나만** 실제 질감과 색을 가진다(나무문, 황동 손잡이). — `cinematographer`(팔레트) + `set-builder`
3. **그레이드:** 채도를 거의 빼고, 그림자는 차갑게, 하이라이트는 0.6에서 누르고, 비네트와 옅은 안개, 고운 필름 그레인을 깐다. 실제 사진도 **같은 그레이드**(흑백에 가깝게, 그레인, 비네트)라 3D와 이어진다. — `cinematographer`
4. **카메라:** 모든 컷이 움직인다.
   - 드론 부감에서 천천히 내려가거나 밀어 들어가기(동네·집 설정 컷)
   - 문으로 다가가기 → **손잡이 접사**(얕은 심도, 배경이 흐림)
   - 인물 **뒤에서 따라가기**(등·어깨 너머)
   - 창·벽 앞 옆으로 흐르기
   - 회의실 고정 와이드에 아주 느린 밀기

   한 장면은 "설정(부감) → 접근 → 디테일(접사) → 인물" 순서로 짠다. — `cinematographer`(카메라 프리셋), `storyboard-director`(배치)
5. **인물:** 옷(셔츠·치마·재킷·바지)과 머리카락이 있는 사실적 인물이다. **걷는 동작이 실제로 있고**, 얼굴은 뒷모습·원경·어둠으로 피하거나 흐리게 처리한다(수사관 회의 장면). 의자에 앉은 사람, 서 있는 사람, 걸어가는 사람. — `character-animator`
6. **제목·이름 카드:**
   - 왼쪽 아래에 **타자 치듯 한 글자씩**(끝에 네모 커서 ▌) 나온다: "2004년 10월 5일 화요일" + 작은 회색 줄 "일본 히로시마현" + 가는 선 하나.
   - 인물 소개도 같은 틀: "사토미 ▌" + "열일곱 살".
   - 같은 장면 안에서 컷이 바뀌어도 카드는 그대로 남는다. — `motion-designer`
7. **3D 공간 도식:** 도로 위에 **빛나는 빨간 선**(거리·경로)을 그리고, 큰 흰 숫자 "150m"를 장면 안에 세운다. 도식이 별도 검은 판이 아니라 **재연 화면 위에** 얹힌다. 검은 보드 도식도 있지만(레퍼런스 팩: 도식 37%), 거리·위치·경로는 3D 위에 그린다. — `motion-designer`
8. **실제 자료:** 아파트 항공 사진(느린 확대), 사건 현장 보도 사진. 흑백에 가까운 그레이드 + 거친 그레인 + 비네트 + 느린 밀기를 쓰고, 테두리·꼬리표는 없다. 지도는 위성 사진에서 내려오는 줌(HyperFrames `bake-basemap`)이다. — `archive-researcher`(자료) + `motion-designer`(줌·처리)
9. **자막:** 상자 없는 흰 글자, 가운데 아래, 한 줄. — `editor`(자막 스킨은 `motion-designer`가 만든다)

## 4. 검수
- `python3 scripts/look_check.py <스냅샷|렌더>` — 3D는 `--kind 3d`(기본), 실제 사진은 `--kind photo`. 장면마다 1장 이상 범위 안이어야 한다.
- visual-critic은 우리 프레임을 `raw/screen-rec/`의 같은 종류 프레임(부감·접사·인물 뒷모습·회의실·창·사진)과 나란히 놓고 블라인드 판정한다.
- 이 문서의 숫자를 바꾸려면 사람 승인을 받는다(레퍼런스를 다시 재서 고치는 것은 예외로, 근거 프레임을 함께 적는다).
