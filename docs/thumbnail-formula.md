# 썸네일 공식 (썸네일 팀 기준서)

벤치마크 @unlock_kr 썸네일 4장(2026-10~11)을 분석해 원리·구도·색(빨간 단색 포함)을 똑같이 가져온다. 그 썸네일 이미지 파일을 그대로 쓰거나 베끼지만 않는다(`originality.md`).
원본은 `data/benchmark/unlock_kr/raw/thumbs/` 에만 둔다(커밋 금지, 비교용).

> **2026-11-19 개정 — 장르 히트작 76장 분석(`docs/thumbnail-benchmark.md`)이 이 문서보다 우선한다.**
> 바뀐 것: ① 두 줄 큰 글자가 **기본**(히트작 91%), 글자 없는 판은 예외. ② 사람이 화면의 30~60%(히트작 86%).
> ③ 이미지는 공개 기록 사진 또는 사진처럼 보이는 생성 이미지 — CC0 3D 는 보조. ④ 썸네일 글자와 제목은 같은 문장만 피하고 숫자는 겹쳐도 된다.
> 아래 원리 1(글자 없음)과 "썸네일과 제목 나누기"의 숫자 금지는 이 개정으로 대체됐다.

## 벤치마크에서 읽은 원리 6가지
| # | 원리 | 벤치마크에서 본 것 | 우리 방식 |
|---|---|---|---|
| 1 | **글자 없음** | 4장 모두 글자 0 | 기본판은 글자 없음. 글자판(숫자 + 4~6자)은 A/B 용으로만 |
| 2 | **색 하나가 화면을 지배** | 빨간 단색(4장 중 3장 화면의 30~87%) | **앰버 하나.** 빨간색 비율 15% 넘으면 불합격(`thumb_review.py`) |
| 3 | **튀는 것 하나** | 빨간 군중 속 파란 사람 / 검은 집에서 빨간 빛 새는 지하실 | 두 가지 모드(아래 spot / flood) |
| 4 | **상징물 하나가 화면을 채움** | 웃는 입 클로즈업, 공구 4개, 집 한 채 | 초점(상징물)이 화면의 8~65%, 휴대폰 크기(168px)에서도 무엇인지 보일 것 |
| 5 | **직접 보여주지 않고 암시** | 피해자·현장 대신 공구·지하실·웃음 | 사건의 **기록에 있는 물건·장소**로 암시. 시신·피·실제 얼굴 금지 |
| 6 | **필름 질감** | 강한 그레인, 눌린 검정, 사실적 질감 | 사실적 3D(CC0 스캔 모델·질감) + 그레인 13 + 비네트 |

## 클릭하고 싶어지는가 (2026-11-19 사용자 피드백으로 추가)
"잘 읽히는가"만으로는 부족하다. 시험 썸네일(종이 한 장)은 숫자는 다 통과했지만 클릭하고 싶지 않았다. 아래 넷 중 **둘 이상**을 갖춰야 한다.
1. **감정** — 불안·찝찝함·섬뜩함. 정보(글자, 서류)는 감정이 아니다.
2. **사람이나 사람의 흔적** — 실루엣, 뒷모습, 손, 신발, 누운 자세. 얼굴·실제 인물은 금지.
3. **이상한 점** — 평범한 것 속 잘못된 것 하나(너무 단정한 시체, 하나만 다른 색, 있어야 할 것이 없음).
4. **뜻을 몰라도 생기는 질문** — 외국어·사건을 알아야 이해되는 상징은 약하다. 모르는 사람도 "왜?"가 생겨야 한다.
- **사진처럼 보여야 한다.** 벤치마크는 사진(또는 사진 같은 생성 이미지) 질감이다. CC0 3D 인물을 가까이 찍으면 마네킹처럼 보인다(c3 시험).
  인물을 크게 쓰려면 사진 같은 생성 이미지가 필요하다(HeyGen 생성 이미지 등, 사람이 로그인·비용을 결정). 3D로만 갈 때는 사람을 작게·실루엣으로, 상징물은 실물 스캔 소품으로.

## 썸네일과 제목 나누기 (같은 말을 두 번 하지 않는다)
| | 썸네일 | 제목 |
|---|---|---|
| 역할 | **호기심**: 이상한 장면 하나 | **내용 요약**: 공식 하나(`docs/script-formula.md` 제목 공식) |
| 글자 | 기본은 **글자 없음**(벤치마크 히트작 252만·64.6만 모두 글자 0). 글자판은 A/B 용, **2~8자** 큰 줄 + 짧은 작은 줄 | 숫자+결과형 / 모순+이유형 / 뜻밖의 결말형 / 최상급형 |
| 담는 것 | 제목에 **없는** 감정·이상한 점·질문 | 사건이 무엇이고 어떻게 끝났는지 |

- **규칙(개정):** 썸네일 글자와 제목이 같은 문장을 반복하면 안 된다. 숫자·핵심어 하나가 겹치는 것은 괜찮다(장르 히트작도 그렇다). `thumb_review.py` 는 숫자 아닌 단어가 2개 이상 겹치면 경고한다(`overlap`).
- 질문형 글자는 사건 자체에 묻는다("누가 잘라냈나", "이 남자는 누구인가"). "나만 몰랐던 ~" 같은 정보 채널 말투는 쓰지 않는다.

| 나쁜 짝 (반복) | 좋은 짝 (나눔) |
|---|---|
| 썸네일 "73년 / 이 남자는 누구인가" + 제목 「73년 만에 이름을 찾은 해변의 남자」 → "73년" 반복 | 썸네일 **"상표가 없다 / 누가 잘라냈나"** + 제목 「73년 만에 이름을 찾은 해변의 남자」 |

- 컨셉 페이지에 제목을 적어 두면 검수가 짝을 확인한다: `<!-- title: "73년 만에 이름을 찾은 해변의 남자" -->`.

## 세 가지 모드 (`scripts/thumb_grade.py --mode`)
- **spot — 어둠 속 앰버 하나.** 화면 전체를 거의 검은 회색으로 누르고 **초점만 앰버**. 영상 본편의 3D 스타일(무채색 + 앰버 초점)과 같은 언어라 채널이 하나로 보인다. 기본값.
- **flood — 앰버 바다 속 다른 색 하나.** 화면 전체를 앰버로 물들이고 **초점만 차가운 색(cold) 또는 창백한 색(pale)**. 같은 것이 여러 개 있는 장면(군중, 물건 여러 개, 서류 더미)에서 "하나만 다른 것"을 보여줄 때.
- **tone — 어둠 속 앰버 빛.** 화면 전체를 밝기대로 검정 → 앰버 → 크림으로. 앰버가 '칠'이 아니라 '빛'이 된다. 인물을 칠하면 플라스틱처럼 보일 때 쓴다.
- 한 편당 모드를 섞어 2~3안을 만들고 사람이 고른다.

## 상징물 고르기 (thumb-director)
1. 후보는 **facts.md / 기획안에 실제로 나오는 것만**: 증거물, 장소, 문서, 숫자. 원문에 없는 세부를 만들지 않는다.
2. 좋은 상징물 = (a) 처음 보는 사람도 "저게 뭐지?" 하게 만들고 (b) 영상을 보면 의미가 풀리는 것. 제목과 겹치지 않고 **보완**한다.
3. 장면 하나에 상징 하나. 넓은 풍경·여러 인물·작은 소품 나열 금지.
4. **사진 규칙(2026-11-19 개정, 사용자 승인):** 공개 기록 사진(저작권 만료·공공 기록, 예: 1955년 이전 호주 사진)은 **실제 인물 얼굴도 쓴다** — 장르 히트작의 75%가 실제 얼굴.
   조건: 출처·저작권을 `thumbnail/src/SOURCES.md` 에 기록 / 상처·피·잔혹한 사진 금지 / 피해자 유족·생존자·미확정 관련자 사진 금지 / 언론사 사진처럼 저작권이 살아 있는 사진 금지.
   기록 사진이 없을 때는 사진처럼 보이는 생성 이미지(사람이 결정), 3D 인물은 얼굴 없는 실루엣까지만. 도구: `scripts/thumb_photo.py` → `scripts/thumb_text.py`.
5. 벤치마크 구도(공구 일렬 배치, 군중 속 한 사람, 입 클로즈업, 정면의 집 한 채)는 써도 된다. 다만 특정 썸네일 한 장을 그대로 베낀 수준(`bench_hash` 6 미만)이면 다시.

## 만들기 (thumb-builder)
- 컨셉마다 `episodes/<ep>/thumbnail/cN.html` 한 장. `thumbkit/thumbkit.js` 로 장면을 짓는다(모델·질감·HDRI·종이·조명·초점 표시).
- 페이지 머리 주석: `assets:` (필요한 CC0 자산) / `grade:` (모드와 옵션) / `text:` (글자판 문구, 선택) / `title:` (함께 쓸 제목).
- `bash scripts/thumbnail.sh episodes/<ep> [cN ...]` → `thumbnail/out/` 에 원본·마스크·완성본·글자판·검수표.
- 자산은 `python3 scripts/thumb_assets.py search <단어>` 로 찾는다(Poly Haven, 전부 CC0). 캐시는 커밋하지 않는다.
- 사실적으로 보이게: 실제 크기(미터)로 짓고, 카메라는 물건 가까이(초점이 화면의 15% 이상), 빛은 한쪽에서 하나 + 아주 약한 환경광.
  밝은 종이·흰 물체는 노출을 낮춰(0.6~0.8) 하얗게 날아가지 않게.

## 검수 기준 (thumb-critic, `scripts/thumb_review.py`)
| 항목 | 합격 |
|---|---|
| 168px(휴대폰 추천)·246px(검색)·360px(홈)에서 상징물이 무엇인지 말할 수 있다 | 필수 |
| 초점 크기 `focus_area` | 8~65% |
| 초점 대비 `contrast` | 40 이상 |
| 작은 화면 복잡도 `clutter` | 22 이하 |
| 오른쪽 아래(재생시간 배지)에 초점이 없다 | 필수 |
| 베낀 이미지 아님 `bench_hash` | 6 이상 |
| 빨간색 비율 `bench_hue` | 참고용(기준 없음) |
| 사실: 그린 것이 facts.md 에 있다, 금지 묘사 없음 | 필수 |
| 제목과 함께 읽을 때 질문이 생긴다(제목이 답을 말하지 않는다) | 필수 |
| 글자판과 제목이 같은 문장이 아니다 `overlap`(숫자 제외 겹친 단어) | 1개 이하 |
| 클릭하고 싶어지는가: 감정·사람·이상함·질문 중 둘 이상 | 필수 |
| 사진처럼 보인다(마네킹·CG 상품 사진 느낌 아님) | 필수 |

숫자는 참고다. 숫자가 통과해도 168px 에서 무엇인지 모르겠으면 불합격, 숫자가 걸려도 이유가 분명하면(예: 의도적으로 작은 종이 한 조각) 보고하고 남긴다.
