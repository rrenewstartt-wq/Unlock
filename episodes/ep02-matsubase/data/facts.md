## 틀린 통념·고쳐 쓸 것
- '장기 모임에서 다툼' → 장기 친구 넷의 **술자리**(지인 집 연회 → 피해자 집). '장기 모임'이라는 행사는 1차 자료에 없음.
- '1997년 검찰 창고에서 발견' → 1997년 ✅, '창고'는 근거 없음. "검찰이 보관하던 증거물 속에서".
- '기소 직후부터 압수돼 있었다' → 기소(2/10) **나흘 뒤 2월 14일** 경찰이 집에서 발견, 4월 5일 검찰 송치(첫 공판 사흘 전).
- '자백할 때부터 천을 태웠다고 했다' → 천 이야기는 첫 자백 **16일 뒤 2월 5일** 처음 나옴.
- '칼날에 천을 감았다' → 조서는 "손잡이와 날 이음부(柄と刃の接合部)에 5~6번".
- '검찰이 구형을 포기했다' → 살인에 유죄 주장을 안 했을 뿐, 별건에 징역 2년 구형.
- '재심에서 완전 무죄' → 살인 무죄 + 별건 징역 1년(미결구금 산입).
- 위키의 '2월 14일 기소' → 기소는 2월 10일(2월 14일은 소매 천 발견일).
- 위키의 '1999년 3월 26일 가석방' → 1차 판결은 **3월 25일**. 구원회 연표의 '7월 22일 만기 출소'는 형기 종료일.
- '자백까지 74시간 / 72시간 / 63시간 / 81시간' 혼재 → 자막은 1심 판결의 "13일간 9번, 약 74시간(식사·휴식 포함)".
- 2심 배상액 '약 2,300만 엔'(교도)과 '2,381만 엔'(구마니치) 혼재 → 같은 판결, 표기 차이.
- 전수대 논문의 "경찰관이 개시한 증거물" 표현은 다른 자료(구마모토지검 개시)와 어긋남 → 쓰지 않음.
- 재심판결 공개본에서 감정인도 'C'로 적혀 있음(익명 처리 겹침) → "C의 감정"이라고 쓰지 말 것.

## 일부러 쓰지 않은 것
- 진범 추측, 다른 술자리 참석자(지인 부부)나 이웃을 의심하게 만드는 서술. 공개되지 않은 판본(구마니치 게재 판결 요지 스캔)에 나온 피해자·참석자 실명.
- 피해자·유족·참석자·발견자·수사관·검사·해부의·첫 국선변호인의 실명 → 실명 미사용(근거 칸에 역할로만).
- '검찰이 천을 숨겼다/握りつぶし' 같은 의도 단정 → 판결이 말한 것은 "법정에서 밝히지 않은 것은 주의의무 위반"(국가 상고 중). 의도는 어느 판결도 확정하지 않음.
- 피해자가 했다는 모욕적인 말, 생활보호 소문 등 고인·미야타 씨의 사생활.
- 상처·피·시신 묘사. 상처는 '8번·14번 상처의 깊이·폭 숫자 vs 칼 모양' 도식으로만.
- 무죄 확정자를 범행 장면에 둔 재연. 자백 내용은 '조서에 적힌 이야기'로, 화면은 문서·도식.
- 와병·치매 모습 재연. "소식을 전해 들었다" 수준의 서술만.
- A형 혈흔 조각(5장 중 1장): 판결문에 사실로 있으나 무슨 의미인지 판단이 없어 쓰지 않음.
