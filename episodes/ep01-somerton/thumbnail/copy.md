# ep01 서머턴 맨: 썸네일 문구 후보 (2026-11-19, thumb-copywriter)

기준: `docs/thumbnail-copy.md`(히트 76장 vs 하위 36장에서 묶은 문구 공식 F1~F7). 사실은 `data/facts.md`만 쓴다(아래 "L번호" = facts.md 줄 번호).
판: 1948년 경찰 기록 사진(얼굴, 오른쪽에 크게, `out/photo-p3.jpg`) + 왼쪽 아래 두 줄(위 흰 줄 8~16자 / 아래 앰버 큰 줄 6~13자, 공백 포함).
사용자 피드백: 기존 세 문구가 "약하다".

## 기존 문구가 약했던 이유 (공식으로 보면)
- "해변에서 발견된 남자 / 73년간 이름이 없었다": 머리 명사(남자)가 위 줄에 있고 큰 줄은 "~다" 문장이다. 히트작 큰 줄 67개 중 "~다" 문장은 1개뿐이다. 결과도 이상한 사실도 없고 "73년"만 남는다.
- "73년 동안 아무도 몰랐다 / 이 남자는 누구인가": 위 줄이 "~다"로 끝나고(히트 5%, 하위 22%) 큰 줄은 얼굴과 같은 말만 한다.
- "지갑도, 신분증도 없었다 / 옷의 상표는 전부 잘려 있었다": 두 줄이 모두 문장이라 하위작과 같은 모양이다. 아래 줄도 15자로 길다. 소재(잘린 상표)는 강하다.
- 고칠 방향: **위 줄은 수식(~없이/~알았던/~속), 아래 줄은 결과가 붙은 명사**로 쓴다(F1·F2). 얼굴이 "이 남자"를 이미 말하므로, 글자는 얼굴이 말하지 못하는 이상한 사실을 말한다.
